# DigitalNomad 통합 개선 2~6단계 실행 기록 (2026-11-21)

> 이 문서는 코드·고정 데이터·공식 원문에서 확인한 사실을 기록한다. 특정 일자리 지원·혜택 수급·투어 예약이 가능하다는 확정 판정은 아니다. 공개 운영 상태는 GitHub Actions 및 실제 페이지에서 별도로 확인한다.

## 2단계 — 코드·기능 감사

- **계획:** 문성/니콜 채용, 복지, 한국어·스페인어 강좌, 투어, 실행의 수집·중복·자격·추천·UI·브라우저 상태·CI 경로 감사. 실제 결함, 설계 위험, 미측정 가설 구분.
- **독립 사전 리뷰:** worker-1. 재수집과 사용자 DB 변형 금지, 좋은 후보 누락과 부적격 후보 노출을 함께 조사하도록 범위 수정.
- **수행 근거:** `scripts/collect-jobs.mjs`의 단기·시급 공고 사전 제외, `scripts/collect-tours.mjs`의 무료 강제, `public/household/index.html`의 과도한 수급 가능 문구, `public/munseong/nicole-feed.js`의 `possible`→`korea` 취급, 추천·보관·IndexedDB 분리 검토.
- **독립 사후 리뷰:** 다른 worker-2. 단기/투어 하드 범위는 코드상 결함, 니콜 점수와 실제 순위 문제는 데이터로 재현할 것을 권고. 구체적인 누락 *전체 건수*는 감사에서 측정하지 않았다.

## 3단계 — 실제 데이터·추천·UX 기준선

- **계획 및 독립 사전 리뷰:** worker-1이 비확률표본의 precision/recall 과대해석, 공식 출처와 현재 모집 혼동, 실제 기기 미검증을 주의하도록 제안.
- **기준 자료:** 당시 로컬 추적 피드 `docs/jobs.json` 문성 297건, `profiles/dubu/public/jobs.json` 니콜 186건(raw), 화면 변환 162건; 복지 43건, 한국어 강좌 6건, 스페인어 강좌 1건, 투어 16건(모두 무료), 실행 17건. 날짜별 변동 가능.
- **검증:** 기존 주요 Playwright 37/37, 390px 크기 브라우저 경계와 IndexedDB 복원, 공식 전주관광재단 및 전주 관광 자료의 유료 체험 누락 사례 2건 확인. 니콜 raw score 미설정으로 공통 추천 카운트 0, 실제 화면 후보는 존재.
- **독립 사후 리뷰:** 다른 worker-2가 기준선으로 조건부 수용. 인간 평가자 라벨, 전체 원문 샘플, 정확도·재현율, Android/iOS 실기기·실제 지원 결과는 미측정.

## 4단계 — 증거 기반 종합 설계

- **독립 사전 리뷰(worker-1):** 복지 과장 정정을 P0로 상향; 단기 공고의 *수집 복원*과 *추천 승격*을 구분; 유료·무료·미상 투어를 출처와 확인일별로 정규화; 니콜 현재 공고/과거 보관을 함께 유지.
- **결정:** P0 복지 오해·단기 하드 제외·투어 가격/실패 복구; P1 니콜 우선검토와 개인 숨김 피드백(기존 DB 포맷 안전 범위); P2 계측 없이 수집기/CI/DB 전면 교체 금지.
- **독립 사후 리뷰(worker-2):** 가격 원문 충돌, `lastCheckedAt` 대 `updatedAt`, source failure 대 정상 0, 저장/숨김/백업 상태 다중탭 호환성을 품질 게이트에 추가.

## 5단계 — 통합 구현과 독립 사후 반례 수정

- **독립 사전 리뷰(worker-1):** 사용자 데이터를 건드리지 않는 논리·표시 개선, official evidence 불확실성, 작은 fixture→전체 E2E 순으로 검증 지시.
- **문성:** 단기·알바 사전 삭제 제거; 고용형태(`permanent/contract/freelance/part_time/task/mixed/full_time/unknown`)와 지급 단위 별도 표시, 불확실 자격을 적합 확정처럼 표현하지 않음.
- **니콜:** 지역 지원 `possible`은 한국 가능 확정으로 승격하지 않음; 현재 수집+명백 불가 아님 후보만 '원문 검토' 전용 목록/필터로 표시. 이전/전체/수동/저장 공고 유지, 적합도 동률인 경우에만 현재 후보를 먼저 보임.
- **상태:** 사용자 선택 숨김 사유 enum을 기존 IndexedDB 저장 문서/백업 v2 확장으로 저장·복원, company/source 숨김·undo·다중탭의 기존 ID 유지. 민감한 자유형 사유를 서버로 보내지 않음.
- **투어:** 공용 `public/tours/price-status.js`가 수집기·화면의 `free/paid/unknown`을 동일 계산. 가격 충돌은 `unknown` 취급. 기존 curated ID 8건과 기존 feed ID를 유지, 공식 유료 체험 2건 추가. 원문 확인일과 피드 갱신 시각 분리, 수집 실패/부분 성공/성공 0건을 구분, fallback은 재검증으로 표시하지 않음. 콘텐츠 아이디어와 교통·촬영·국적·예약 불확실성 구분.
- **복지·강좌·실행:** 복지는 '검토 후보·자격 미판정'으로 정정. 강좌·실행의 원본 자료/기존 로컬 관리 상태는 변경하지 않고 해당 기능 회귀 검증.
- **독립 사후 리뷰(worker-2):** 숨김 관리에서 이유 미삭제, 투어 프론트/백 가격 상충, 다중탭 이유 고아 데이터, 정규직 전환 '현재 정규직' 오분류를 지적. 각각 수정 및 독립 순수 코드·반례 재검토 완료; 새 확정 P0 없음.
- **회귀:** 최종 구현 작업트리 `npm.cmd run check` PASS (니콜 단위 테스트 65개 포함), 브라우저 전체 `Playwright 141/141 PASS` (2026-11-21 로컬 fixture, Windows Chromium). 초기 실패 4건은 변경된 정보 문구/모듈 수/비동기 대기/영어 번역으로 각각 원인 확인 후 수정. **이 PASS는 실기기·실제 지원 가능성 검증이 아니다.**
- **투어 격리 재수집:** 기존 피드 16건 → 읽기 전용 새 수집 결과 21건 (17 무료, 2 유료, 2 가격 미상), 기존 ID 16/16 유지. 실제 후보/모집 상태는 변동 가능.

## 6단계 — 배포·운영 계획, 독립 게이트

- **사전 독립 리뷰(worker-1):** 조건부 GO. ① 새 JS 모듈·테스트 파일 포함하여 명시 파일만 Git에 추가 ② 원격 feed-only bot 커밋과 경쟁을 확인하고 force/reset 없이 통합 ③ 최종 코드 SHA에서 CI의 npm check/Playwright/정적 빌드·자동 채용/투어·니콜 피드 갱신 확인 ④ Pages 실제 배포 SHA와 6개 HTML/3개 JSON 응답, 사용자별 추천·가격 불확실성·390px·링크 확인 ⑤ 다른 worker-2의 사후 독립 리뷰.
- **배포 중단/롤백:** 새로운 비-feed 원격 변경·충돌, 권한 부족, CI/Pages 실패, 안정 ID/피드 형식 파손, 개인정보·사용자 파일 손실은 STOP. 되돌리기는 강제 초기화 아닌 `git revert`와 재배포를 기본으로 하며, 코드·피드 스키마 호환을 같이 검증. 브라우저 개인 기록을 자동 삭제하지 않는다.
- **공개 운영 증거:** 배포 결과에 대한 최종 채팅 보고의 Actions run ID, commit SHA, Pages 응답을 참조한다. 이 문서 작성 시점의 CI 성공이나 공개 배포 성공을 가정하지 않는다.

## 미해결·비교 한계

실제 전체 구직시장·복지·체험 모집의 분모, 정량적인 추천 정확도/재현율, 실제 고용주 지원 가능성·수급 판정, 외국인 참여·촬영 허가, Android/iOS/VoiceOver·NVDA 실기기 결과, 유료 체험의 실시간 예약 좌석은 미확인이다. 전주공예품전시관 공식 자료 상단의 '무료'와 상세 유료 체험별 8,000~20,000원은 서로 상충하므로 카드에 가격 확인 경고를 넣었다. Traddy 공식 체험 1인 10,000원은 안내 당시 확인 값이다. 공식 원문을 최종 판단의 근거로 삼아야 한다.
